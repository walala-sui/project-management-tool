# 任务日历选择 + 人员信息完善 + 甘特图独立页 — 设计文档

> 日期: 2026-07-31
> 状态: 已实现
> 说明: 三个UI改进合并为一轮开发。

## 功能概述

### 1. 任务日期改为日历选择

任务表中开始/结束日期由文本输入改为 `<input type="date">` 日历控件。

**关键设计：**
- 替换 `contenteditable="true"` 文本单元格为 `<input type="date">` 
- 通过 `onchange` 事件更新任务数据
- 日期变更时触发甘特图刷新

### 2. 人员信息完善 + 成员列 + 任务编辑弹窗

**2a. 负责人显示优化**
- 下拉选项格式从 `张工` 改为 `张工 (硬件部)`
- 数据模型不变，仍用 `resourceId: ""`

**2b. 新增成员列**
- 任务数据模型新增 `memberIds: []` 字段
- 在负责人列后新增「成员」列
- 点击弹出多选面板（checkbox风格），从人员库中选择
- 显示格式：`张工、李工` 或 `-`

**2c. 任务编辑弹窗**
- 项目详情工具栏新增「编辑任务」按钮
- 选中任务后点击，弹出表单弹窗编辑所有字段
- 字段：任务名称、负责人（下拉）、成员（多选checkbox）、开始日期、结束日期、进度（下拉0/20/40/60/80/100）、前置任务（下拉）、层级（0/1/2下拉）

### 3. 甘特图独立页面

- 项目详情页移除右侧甘特图分栏面板，任务表格占满全宽
- 工具栏新增「查看甘特图」按钮
- 点击跳转到全屏甘特图页面，复用 renderGantt() 逻辑，全宽布局
- 甘特图页面保留返回按钮

## 前端改动

### 项目详情页布局

- 移除 `.detail-layout` 双栏布局
- 移除 `#gantt-panel` 面板
- 任务表格占满宽度

### 新增页面

- `#page-gantt` 甘特图独立页，用于展示单个项目的全屏甘特图
- 路由：`showPage('gantt', projectId)`

### 新增全局状态

```js
state.ganttProjectId  // 甘特图页面当前项目ID
```

### 数据模型变更

任务对象新增字段：
```json
{
  "memberIds": ["r1", "r3"]  // 新增，成员ID数组
}
```
