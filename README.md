# 项目管理工具

轻量级项目管理工具，适用于中小团队的项目进度与人员安排管理，MS Project 风格。

## 功能

| 模块 | 说明 |
|------|------|
| **看板** | 全局项目概览 + 延期风险预警（含责任人和部门），仅显示进行中项目 |
| **项目列表** | 按「进行中/暂时搁置/已完成」三区分组，状态可快速切换 |
| **项目详情** | 任务层级表 + 甘特图 + 任务编辑弹窗 + CSV导出 |
| **人员视图** | 按部门管理团队，跨项目任务汇总（含负责人+成员），点击姓名看甘特图 |
| **系统设置** | IP 白名单管理 + 项目模板管理 + 看板阈值设置（密码验证） |

### 任务管理

- **层级结构** — 缩进/升级调整父子关系，支持 WBS 编号
- **状态切换** — 点击循环：待开始 → 进行中 → 搁置，完成判定（进度100%）
- **搜索筛选** — 负责人/成员支持输入文字搜索
- **进度追踪** — 0→1%→20%→40%→60%→80%→100% 步进循环
- **实际完成时间** — 完成时自动记录，列表和导出均包含
- **四象限优先级** — 任务/项目支持 Q1~Q4 优先级，列表直接下拉切换
- **卡点/里程碑** — 点击图标标记，看板自动汇总
- **成员协作** — 任务支持负责人 + 多选参与成员
- **数据导出** — 项目任务 / 人员工作安排一键导出 CSV（Excel 直接打开）

## 快速开始

```bash
# 1. 安装依赖（仅需一次）
npm install

# 2. 启动
# Windows: 双击「启动桌面应用.vbs」
# 命令行: node server.js
```

浏览器自动打开 `http://localhost:3000`

## 技术栈

| 层 | 技术 |
|----|------|
| 前端 | HTML + CSS + JavaScript（零框架依赖） |
| 后端 | Node.js + Express |
| 存储 | JSON 文件（`data/` 目录） |
| 甘特图 | 手绘 SVG |
| 导出 | CSV（UTF-8 BOM，Excel 直接打开） |

## 架构

```
server.js          # 后端入口 (~280行)
├── utils.js       # 共享工具模块
├── public/
│   └── index.html # 前端单页应用
└── data/          # JSON 数据存储
```

## 部署到服务器

1. 服务器安装 Node.js
2. 复制整个文件夹到服务器
3. 运行 `npm install`
4. 运行 `node server.js`（或用 pm2 守护）
5. 确保防火墙放行 3000 端口
6. 首次部署后在系统设置中添加 IP 白名单
7. 团队成员通过 `http://服务器IP:3000` 访问

## 安全

- IP 白名单中间件：非授权 IP 返回 403，支持 CIDR 网段
- 本地访问（127.0.0.1）始终放行
- 管理密码保护设置页面

## 数据备份

直接复制 `data/` 目录即可。所有数据为 JSON 格式，可用任意文本编辑器查看编辑。
