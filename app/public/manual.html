项目管理工具 — 使用手册

适用于中小团队的项目进度与人员安排管理

快速开始

启动方式

方式操作说明
推荐双击 启动桌面应用.vbs服务器静默启动，自动打开浏览器
命令行双击 启动服务器.bat带命令行窗口，适合调试
手动node server.js终端启动，浏览器访问 localhost:3000
首次使用：先运行 npm install 安装依赖（只需一次）。之后每次直接双击 VBS 即可。

看板

进入工具后默认显示看板。顶部四个统计卡片：项目总数、总任务数、有风险项目数、风险任务数。

每个项目一张卡片，双进度条对比：

  • 蓝色 = 任务完成进度（已完成任务数 / 总任务数）
  • 橙色 = 时间消耗进度（已过天数 / 计划总天数）

当时间进度超过任务进度 20% 以上，卡片左侧出现红色边框提示延期风险。

风险任务汇总表

底部列出所有延期或临近超期的任务，包含：

  • 延期 — 结束日期已过，但进度不到 100%
  • 预警 — 时间进度超前任务进度 20% 以上

每行显示：项目名（可点击跳转）、任务名、责任人、部门、结束日期、当前进度。

项目列表

列出所有项目，每行显示项目名称（可点击进入详情）、起止日期、任务完成数和进度条。

点击 + 新建项目 创建新项目，填写名称、描述和起止日期。删除按钮移除项目（含所有任务）。

项目详情

点击项目名进入核心工作区——左侧任务表格 + 右侧甘特图。

表格列说明

开始 / 结束双击编辑日期，修改后甘特图自动更新

任务操作

选中操作栏

点击行左侧单选框选中任务，然后使用工具栏按钮：

按钮作用
→ 缩进增加一层缩进，设为上方最近低层级任务的子任务
← 升级减少一层缩进
↑ 上移 / ↓ 下移调整任务在列表中的排列顺序
删除任务删除选中任务及其所有子任务
缩进/升级/移动后选中状态保持，可以连续操作同一个任务。

进度与完成

点击进度条以 20% 为步进循环：0 → 20 → 40 → 60 → 80 → 100 → 0

到达 100% 后，完成按钮变为绿色可点击状态。

点击完成后：

  • 任务自动保存到磁盘
  • 从活跃列表移除，移至表格底部的"已完成任务"折叠区
  • 按结束月份分组，默认折叠

折叠区操作：

  • 点击月份标题行 → 展开/收起该月已完成任务
  • 展开后每个任务有恢复按钮 → 点击移回活跃列表

内联编辑

双击任务名称、日期、前置任务等单元格直接编辑。Tab 跳转到下一个可编辑单元格。

编辑后顶部出现"保存修改"按钮，点击保存。标记完成/恢复自动保存。

甘特图

右侧面板实时显示任务时间线：

  • 顶部显示月份刻度
  • 红色虚线 = 今天的位置
  • 不同层级任务不同颜色（蓝/绿/橙）
  • 已完成的进度部分填充为绿色
  • 编辑日期或进度后自动更新

人员视图

按部门分组显示所有人员。顶部支持：

  • 部门筛选 — 只显示特定部门成员
  • 人员筛选 — 只显示特定人员
  • 编辑人员 — 新增、编辑、删除人员

人员卡片

每张卡片显示：

  • 姓名（可点击查看甘特图）
  • 任务统计：总共 X 个，进行中 X 个，完成 X 个
  • 活跃任务表格：项目、任务名、日期、进度
  • 已完成任务按月份折叠（点击展开）
  • + 分配任务 按钮

人员甘特图

点击人员姓名弹出甘特图弹窗，显示该人员所有跨项目任务的时间分布。超期任务红色标记。

直接分配任务

点击卡片上的 + 分配任务 → 输入名称、选项目、选日期 → 确认。任务同时写入人员名下和对应项目中。

常见操作场景

场景一：新项目启动

  1. 项目列表 → + 新建项目 → 填写名称和日期
  2. 进入详情 → + 添加任务 → 编辑名称、负责人、日期
  3. 选中任务 → 缩进/升级调整层级 → 设前置任务
  4. 右侧甘特图确认时间线

场景二：每周进度更新

  1. 进入项目详情 → 逐个点击进度条更新
  2. 100% 的任务 → 点击完成归档
  3. 检查甘特图 → 保存修改

场景三：检查延期风险

  1. 打开看板 → 查看红色延期任务
  2. 点击项目名跳转详情 → 定位问题
  3. 可点击人员名看甘特图了解资源占用

场景四：给同事分配工作

  1. 人员视图 → 找到同事 → + 分配任务
  2. 选择归属项目和起止日期 → 确认
  3. 任务自动写入项目任务列表

场景五：月度项目复盘

  1. 进入项目详情 → 查看底部已完成任务折叠区
  2. 按月份展开查看当月完成情况
  3. 看板检查整体健康度

数据备份

所有数据以 JSON 文件存储在 data/ 目录：

  • data/resources.json — 人员库
  • data/projects/*.json — 项目文件
备份：复制整个 data/ 文件夹。
恢复：将备份的 data/ 覆盖回来。

JSON 格式可直接用记事本打开查看和编辑，方便应急处理。
