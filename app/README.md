# 项目管理工具

适用于中小团队的轻量级项目管理工具，按项目跟踪任务进度和人员安排，MS Project 风格。

## 快速开始

```bash
# 1. 安装依赖（仅需一次）
npm install

# 2. 启动
双击 启动桌面应用.vbs
```

浏览器自动打开 `http://localhost:3000`。

## 功能

| 模块 | 说明 |
|------|------|
| **看板** | 全局项目概览 + 延期风险预警（含责任人和部门），仅显示进行中项目 |
| **项目列表** | 按「进行中/暂时搁置/已完成」三区分组，状态可快速切换 |
| **项目详情** | 任务层级表 + 甘特图 + 任务编辑弹窗 + 导出，支持日期/前置任务/缩进/移动 |
| **人员视图** | 按部门管理团队，跨项目任务汇总（含负责人+成员任务），点击姓名看甘特图 |
| **系统设置** | IP 白名单管理 + 项目模板管理 + 看板阈值设置（密码验证） |

### 任务管理

- **层级结构** — 缩进/升级调整父子关系，支持 WBS 编号
- **日历选择** — 开始/结束日期点击弹出日历控件
- **搜索筛选** — 负责人/成员支持输入文字搜索筛选
- **编辑弹窗** — 选中任务后一键弹窗编辑全部字段
- **状态切换** — 点击状态列循环切换：待开始 → 进行中 → 搁置，完成判定不变（进度 100%）
- **进度追踪** — 0→1%→20%→40%→60%→80%→100% 步进循环
- **时间进度** — 自动计算已过天数占比，超时预警
- **实际完成时间** — 标记完成时自动记录，CSV 导出包含此列
- **完成归档** — 100% 后标记完成，按月份折叠，支持恢复
- **依赖关系** — 前置任务设置，甘特图联动
- **四象限** — 任务/项目支持重要-紧急四象限优先级
- **卡点/里程碑** — 点击图标标记，看板自动汇总
- **成员协作** — 任务支持负责人 + 多选参与成员
- **数据导出** — 项目任务 / 人员工作安排一键导出 CSV（Excel 直接打开）

### 人员管理

- 部门分组，筛选查看
- 人员属性筛选（卡点/负荷/关键人员）
- 点击姓名看跨项目甘特图（周视图）
- 直接分配任务，自动关联到项目
- **成员角色** — 人员视图中区分负责人/成员角色
- **时间筛选** — 按日期范围筛选人员任务显示
- **工作导出** — 按部门+时间范围导出人员工作安排（CSV，含角色列）

### 项目模板

- 新建项目时选择模板，自动生成阶段任务结构
- 项目详情页一键「保存为模板」
- 系统设置中管理模板（创建/编辑任务/删除）

### 安全

- IP 白名单：仅白名单内 IP 可访问，支持 CIDR 网段
- 管理密码验证，本地访问始终放行

## 技术栈

| 层 | 技术 |
|----|------|
| 前端 | HTML + CSS + JavaScript（零框架） |
| 后端 | Node.js + Express |
| 存储 | JSON 文件（`data/` 目录） |
| 甘特图 | 手绘 SVG（不依赖第三方库） |
| 导出 | CSV（UTF-8 BOM，Excel 直接打开） |
| 启动 | VBS 脚本（Windows） |

## 架构


## 部署到团队服务器

1. 在服务器上安装 Node.js
2. 复制整个文件夹到服务器
3. 运行 `npm install`
4. 运行 `node server.js`（或用 pm2 守护）
5. 确保防火墙放行 3000 端口
6. **首次部署后立即在系统设置中添加 IP 白名单**，否则其他人无法访问
7. 团队成员通过 `http://服务器IP:3000` 访问
8. 可选：Nginx 反代 + 基础密码认证
