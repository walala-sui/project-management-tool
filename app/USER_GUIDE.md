# 项目管理工具 — 使用指南

## 启动

**双击 `启动桌面应用.vbs`** — 服务器自动后台启动，浏览器自动打开 `http://localhost:3000`

停止：双击 `停止服务器.bat`。

---

## 导航栏

| 视图 | 用途 |
|------|------|
| **看板** | 进行中项目概览 + 延期风险预警 |
| **项目列表** | 创建/切换状态/删除项目，进入项目详情 |
| **人员视图** | 按部门管理团队，分配任务，时间筛选导出 |
| **系统设置** | IP 白名单管理 + 项目模板管理（需密码） |

---

## 一、看板

顶部统计卡片：进行中项目数、总任务数、延期风险数、提前完成数。

每个项目一张卡片，显示两条进度条：
- **蓝色 = 任务完成进度**
- **橙色/红色 = 时间消耗进度**

时间进度 > 任务进度 + 20% → 红色预警。底部风险汇总表列出所有延期任务及其**责任人**和**部门**。

> 看板只显示「进行中」状态的项目，搁置和已完成的项目不出现。

---

## 二、项目列表

项目按三种状态分区显示，可点击标题栏折叠/展开：

| 状态 | 颜色 | 说明 |
|------|------|------|
| 🔵 进行中 | 蓝色 | 默认展开，看板和人员视图可见 |
| 🟡 暂时搁置 | 橙色 | 默认折叠 |
| 🟢 已完成 | 绿色 | 默认折叠 |

### 项目操作

- 点击项目名称 → 进入项目详情
- **+ 新建项目** → 填写名称、日期、选择模板（可选）
- 点击行内下拉框 → 快速切换项目状态
- **打开** → 进入详情
- **删除** → 删除项目（不可恢复）

### 新建项目时使用模板

1. 点击 + 新建项目
2. 填写项目名称、起止日期
3. 在「项目模板」下拉中选择模板
4. 保存后模板中的阶段任务自动创建
5. 进入项目详情，为每个任务分配人员和具体日期

---

## 三、项目详情（核心工作区）

### 表格布局

| 列 | 说明 |
|----|------|
| # | 单选框，选中后用工具栏操作 |
| 序号 | WBS 编号（如 1.2.1） |
| 任务名称 | 双击编辑，层级缩进显示 |
| 负责人 | 下拉选择，显示「姓名 (部门)」 |
| 成员 | 点击弹出多选面板，可选择多个参与成员 |
| 开始/结束 | 点击弹出日历控件选择日期 |
| **时间进度** | 自动计算：已过天数÷总天数，红色=延期风险 |
| 前置任务 | 依赖的任务（显示WBS序号） |
| 进度 | 0-100%，20%步进 |
| 完成 | 进度100%后可点击 |

### 任务编辑弹窗

1. 点击行左侧单选框选中任务
2. 点击工具栏 **编辑任务** 按钮
3. 弹窗中可编辑全部字段：
   - 任务名称、负责人（下拉）、成员（多选 checkbox）
   - 开始日期、结束日期（日历控件）
   - 进度（0/20/40/60/80/100 下拉）、前置任务、层级（0/1/2）
4. 点击保存 → 表格自动更新

### 选中操作栏

1. 点击行左侧单选框选中任务
2. 使用工具栏按钮：
   - → **缩进**：增加一层缩进
   - ← **升级**：减少一层缩进
   - ↑ ↓ **上下移动**：调整任务排列顺序
   - **删除任务**：同时删除其子任务
3. 缩进/升级/移动后**选中状态保持**，可连续操作

### 进度与完成

- 点击进度条：0→20→40→60→80→100→0 循环
- 到达 100% 后，完成按钮变为绿色可点击
- 点击**完成**后任务自动存档并移至底部按月份折叠
- 折叠区点击月份标题**展开/收起**
- 展开后的任务有**恢复**按钮，点击移回活跃列表

### 甘特图（全屏查看）

- 点击工具栏 **查看甘特图** 按钮
- 跳转到全屏甘特图页面，任务时间线一目了然
- 月份刻度 + 红色虚线标记今天
- 点击 **← 返回项目详情** 回到任务表

### 导出项目

- 点击工具栏 **导出 Excel** 按钮
- 下载当前项目所有任务为 CSV 文件（含层级缩进、负责人、成员、日期、进度、状态）
- Excel 直接双击打开，中文不乱码

### 保存为模板

点击工具栏 **保存为模板** 按钮，输入名称后：
- 当前项目的所有任务（仅名称和层级结构）保存为模板
- 下次新建项目时可直接使用

### 保存

- 编辑后**保存修改**按钮出现，手动点击保存
- 标记完成/恢复**自动保存**

## 四、人员视图

- 按部门分组，每张卡片显示：任务总数、进行中、延期、已完成
- 已完成任务按月份折叠，点击展开

> 人员视图只显示「进行中」项目的任务，搁置和已完成项目的任务不出现。

### 时间范围筛选

- 设置开始/结束日期 → 自动刷新，只显示该时间段内的任务
- 统计数同步更新
- 筛选条件同时影响页面显示和导出内容

### 点击姓名 → 人员甘特图

弹窗显示该人员所有跨项目任务的甘特图（周视图）。超期任务红色标记。

### 分配任务

每人卡片右上角 **+ 分配任务**：
1. 输入任务名称
2. 选择归属项目（仅进行中项目）
3. 选起始/结束日期（日历控件）
4. 确认 → 任务自动写入项目

### 工作导出

- 选择部门、设置时间范围
- 点击 **导出 Excel** → 下载人员工作安排 CSV
- 包含：姓名、部门、项目、任务、起止日期、进度、完成状态
- 延期任务在 Excel 中红色标记

### 编辑人员

右上角 **+ 编辑人员**：
- 新增（输入姓名+部门）
- 编辑（点击编辑修改）
- 删除（确认后删除，不影响已分配任务）

### 部门/人员筛选

下拉选择特定部门或人员，筛选显示。

## 五、系统设置

点击导航栏「系统设置」，输入管理密码（默认：`14`）进入。

### IP 白名单管理

- **添加规则**：输入 IP 地址或 CIDR 网段（如 `192.168.1.100` 或 `192.168.1.0/24`），点击添加
- **删除规则**：点击对应 IP 行的删除按钮
- **本地访问**：服务器本机（`127.0.0.1` / `localhost`）始终不受白名单限制
- **生效范围**：白名单外的 IP 访问时会看到「403 无权访问」提示页

### 模板管理

- **创建空模板**：输入模板名称，点击创建（后续可编辑任务）
- **编辑任务**：点击模板的「编辑任务」按钮，弹窗中管理任务行（名称/层级/工期）
- **添加任务行**：在编辑弹窗中点击 + 添加任务行
- **删除模板**：确认后删除，不影响已创建的项目

## 常见操作场景

### 场景1：新项目启动
1. 项目列表 → + 新建项目 → 选择模板 → 填写日期 → 保存
2. 进入项目详情 → 为各任务分配人员和成员 → 调整日期
3. 选中任务 → 缩进调整层级 → 设前置任务依赖

### 场景2：每周更新进度
1. 进入项目 → 点击各任务进度条更新
2. 选中任务 → 编辑任务弹窗批量修改
3. 100% 的点击完成归档
4. 查看甘特图确认时间线 → 点保存

### 场景3：看延期风险
1. 看板 → 查看红色风险任务
2. 点项目名进入详情 → 定位问题任务
3. 点人员姓名看甘特图 → 了解资源分配

### 场景4：给同事安排工作
1. 人员视图 → 找该同事 → + 分配任务
2. 选项目、日期 → 确认 → 自动关联
3. 或进入项目详情 → 在任务中点击成员列多选参与人

### 场景5：项目暂时搁置
1. 项目列表 → 找到项目 → 下拉切换状态为「暂时搁置」
2. 之后看板和人员视图不再显示该项目
3. 恢复时切回「进行中」即可

### 场景6：项目完成归档
1. 确认所有任务进度100%并标记完成
2. 项目列表 → 切换状态为「已完成」
3. 项目自动归档到已完成分区

### 场景7：导出工作汇报
1. 项目详情页 → 导出 Excel → 得到项目任务清单
2. 人员视图 → 选择部门 + 时间范围 → 导出 Excel → 得到部门工作汇报数据
3. CSV 文件用 Excel 打开，可直接做数据透视和图表

### 场景8：配置IP访问控制
1. 导航栏 → 系统设置 → 输入密码 `14`
2. 添加团队成员的 IP 或内网网段（如 `192.168.1.0/24`）
3. 非白名单 IP 将被拦截
