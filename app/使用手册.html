看板 — 风险预警

进入后默认显示看板，顶部统计卡片展示项目健康度。每个项目双进度条对比：

  • 任务进度 已完成任务占总任务比例
  • 时间进度 已过天数占计划总天数的比例
时间进度超过任务进度 20% 以上时，卡片标红预警。底部汇总表列出所有延期任务及其责任人和部门。

项目详情 — 核心工作区

任务表格

列功能
#单选框，选中后用工具栏操作
任务名称双击编辑，层级缩进显示父子关系
负责人下拉选择，来源于人员库
开始 / 结束双击编辑，甘特图自动联动
时间进度自动计算，红色=延期风险
前置任务依赖的任务 ID
进度点击切换：0→20→40→60→80→100
完成100% 后可点击，自动归档

选中操作栏

选中任务后，顶部工具栏统一操作：

按钮功能
→ 缩进增加层级（设为子任务）
← 升级减少层级
↑↓ 移动调整排列顺序
删除删除任务及子任务
缩进/升级/移动后选中保持，可连续操作。

完成归档

进度达 100% 后点击完成：

  • 任务从活跃列表移至底部按月份折叠
  • 点击月份标题展开/收起
  • 展开后有恢复按钮，可移回活跃列表
  • 完成和恢复均自动保存

甘特图

右侧面板 SVG 手绘甘特图：月份刻度、今天线、进度填充、编辑日期后自动更新。

人员视图

  • 按部门分组，支持部门和人员双筛选
  • 点击姓名 → 弹出跨项目甘特图
  • 每人卡片右上角 + 分配任务 → 自动关联到项目
  • 已完成任务按月份折叠
  • 编辑人员：新增/修改/删除

常见操作场景

新项目启动

  1. 项目列表 → + 新建项目
  2. 进入详情 → + 添加任务
  3. 编辑名称、负责人、日期
  4. 选中 → 缩进调整层级
  5. 设前置依赖任务

周进度更新

  1. 打开项目详情
  2. 点击进度条更新
  3. 100% → 点击完成归档
  4. 查看甘特图确认时间线
  5. 保存修改

延期风险排查

  1. 看板查看红色延期任务
  2. 点击项目名定位问题
  3. 点击人员名看资源分配
  4. 调整排期或资源

分配任务给同事

  1. 人员视图 → 找到同事
  2. + 分配任务
  3. 选归属项目和起止日期
  4. 确认 → 自动写入项目

数据管理

所有数据以 JSON 文件存储在 data/ 目录，可直接用记事本查看编辑。

备份：复制 data/ 文件夹

恢复：覆盖回原位置

部署到服务器

  1. 服务器安装 Node.js
  2. 复制整个文件夹
  3. npm install 安装依赖
  4. node server.js 或 pm2 守护进程
  5. 团队访问 http://服务器IP:3000
